Editor Visual de Fórmulas

100+ bloques pre-armados en 9 categorías (fracciones, integrales, matrices, griegos, operadores). Preview en tiempo real con KaTeX. Modo dual visual/raw.

6 Tipos de Celda

Markdown con toolbar flotante, Code, LaTeX con editor visual, Image con drag & drop, Embed con presets (YouTube, Desmos, CodePen), Raw.

✨

UX Moderna

Click-to-edit, toolbar flotante contextual, insert handles entre celdas, animaciones suaves, temas light/dark, keyboard-first.

⚡

Zero-Server

100% TypeScript, funciona offline sin backend. Core ~25KB, React adapter ~54KB. Arranque instantáneo sin kernel ni compilación.

🔌

Plugin System

Cada feature es un plugin opt-in. Extensible en cada capa — custom cell types, renderers, toolbar actions, keybindings, AI providers.

⚛️

Framework Agnostic

Core puro TypeScript sin dependencias de framework. Adapter React listo. Arquitectura preparada para Vue, Svelte, Solid, Vanilla JS.
